# 接线与板级集成参考

目标板为 Genesys 2，器件 `xc7k325tffg900-2`。摄像头沿用原工程的直插方案：模块 J2 对 JA、J1 对 JB，按针号一一对应。换用其他 OV5640 模块时应按信号和板卡丝印重新核对，不能仅凭插座外观判断方向。

摄像头接口使用 3.3 V 电平并共地；接线调整前断电。以下 FPGA 管脚直接来自本仓库的 `src/constraints/ov5640_photo.xdc`。

| 信号 | FPGA 管脚 | 已注明的扩展口位置 |
| --- | --- | --- |
| SDA | U27 | JA1 |
| RESET_n | U28 | JA2 |
| HREF | T26 | JA3 |
| XCLK | T27 | JA4 |
| SCL | T22 | JA7 |
| VSYNC | T23 | JA8 |
| PWDN | T20 | JA9 |
| D7 | T21 | JA10 |
| PCLK | U25 | JB8 |
| D0 / D1 | U22 / U23 | 按模块直插针序与约束核对 |
| D2 / D3 | W26 / V25 | 按模块直插针序与约束核对 |
| D4 / D5 / D6 | V30 / V29 / T25 | 按模块直插针序与约束核对 |

系统时钟为板载 200 MHz 差分输入 AD12/AD11；RESET 使用 R19。SW0 为模式选择，SW1 为拍照拨码；它们分别接 G19/G25，使用约束规定的 LVCMOS12 电平标准。

| 操作 | 集成系统行为 |
| --- | --- |
| SW0=0 | 连续模式 |
| SW0=1 | 手动拍照，空闲时等待 SW1 稳定翻转 |
| SW1 任一方向稳定翻转 | 手动模式下选择触发之后的有效完整帧；忙碌期间触发不排队 |
| RESET | 清空正在进行的事务，并重新初始化摄像头 |

HDMI 接板卡 TX/OUT，差分数据及时钟约束随 XDC 提供。UART 调试导出默认关闭；摄像头与显示外围不依赖上位机。完整识别还需要私有核心，本仓库没有可直接下载的 bit。

XDC 包含与现有模块层级配套的 CDC、总线偏斜及摄像头时钟入口约束。改变时钟、层级或线路后需要重新进行实现和时序检查，不能直接套用旧系统报告。本次发布验证的是独立仿真，没有重新进行实板验收。
