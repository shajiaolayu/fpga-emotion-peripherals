# 验证范围

统一入口为 `python scripts/run_tests.py`。测试使用明确列出的外围源文件，不搜索上级目录，不加载真实模型，测试数据由 Python 标准库确定性生成。

| 测试 | 验证内容 |
| --- | --- |
| `init_mode_0`…`init_mode_6` | 正常初始化、总线 NACK、错误芯片 ID、回读错误、总线被拉低、启动保护时间、一次回读重试 |
| `fifo` | 满载、溢出、异步读写顺序、指针多次回绕和复位 |
| `prefetch` | 完整帧所有权、最新有效帧、手动模式的新鲜度、忙碌拨动与中途复位 |
| `capture` | RGB565 字节顺序、坐标顺序、残缺字节/行拒绝与复位恢复 |
| `configured_dvp` | 配置寄存器语义与传感器 DVP 模型的连通验证 |
| `roi` | 两种合成图案的独立软件参考，共比较 6912 个灰度输出，验证无效帧拒绝 |
| `loader` | 2304 字节加载顺序、缩略图对应关系、忙碌阻止、中断读取及复位 |
| `controls` | 上电基线、消抖、双向翻转及模式切换 |
| `formatter` | 39 组人工分数，含零值、负值和 int32 极值；百分比合计 100.0%、文本/条形元数据及输入快照 |
| `pipeline` | 当前 overlap/prefetch 通路；三组完整事务、6912 字节输入、照片保持、忙碌触发忽略、连续模式及显示确认协议 |
| `publication` | 实际显示模块的图像/类别元数据同批发布、消隐边界切换、跨时钟确认与复位 |
| `guard_no_test_define` / `guard_synthesis` | 核心测试替身缺少测试宏、或进入综合环境时，必须拒绝编译 |

`formatter` 使用独立浮点指数参考，允许每类最多 0.2 个百分点的查表/舍入误差，同时要求七类整数百分比总和严格为 1000（单位 0.1%）。这验证显示端数学处理，不评价真实分类模型。

`pipeline` 明确使用仿真替身。其分数是人工设定的可区分数列，显示确认由测试台驱动；它验证外围事务，不声称完成真实推理或完整 HDMI 实板验证。

GitHub Actions 在 Linux 干净 checkout 中执行相同测试及发布审计。审计校验公开清单的文件名、SHA-256、未列入清单的文件、敏感产物和可达 Git 历史。它是发布检查工具，不是针对所有未来泄露方式的保证；新增文件应先人工审查，再更新清单。

本次发布不重新统计识别准确率、真实核心性能、整机资源或实板稳定性，也不沿用原工程的测试报告作为公开版的通过证据。
